## Описание

DataCulture Platform — модульное веб-приложение на базе Streamlit для управления образовательными данными студентов НИУ ВШЭ. Платформа включает 6 специализированных модулей для автоматизации процессов обработки оценок, генерации документов и аналитики курсов.

**Ключевые возможности:**
- Модульная архитектура с навигацией `st.navigation`
- Интеграция с облачной БД Supabase (PostgreSQL)
- AI-генерация HTML-контента через Nebius AI
- Пакетная обработка данных с retry-механизмом
- Современный UI в стиле Apple Dark Mode

## Функциональность

### Основные модули

#### 1. Перезачет оценок
- Автоматический расчет итоговых оценок по дисциплинам-пререквизитам
- Учет оценок НЭ, ДПР и внешних измерений (Иннополис)
- Опциональный учет динамики оценок
- Сопоставление студентов по email
- Экспорт результатов в Excel

#### 2. Генератор HTML-карточек
- AI-генерация персонализированных HTML-карточек для email-рассылок
- Использование Nebius AI (модель DeepSeek V4.1 Flash)
- Фирменный стиль НИУ ВШЭ с логотипом
- Предпросмотр готовой верстки
- Кнопки «Скачать HTML» и «Скопировать HTML»

#### 3. Генератор сертификатов
- Генерация текста сертификатов на основе оценок студентов
- Сопоставление дисциплин с описаниями навыков
- Агрегация навыков по уровням оценок
- Массовая обработка с дедупликацией
- Экспорт результатов в Excel

#### 4. Обработка пересдач внешней оценки
- Загрузка результатов внешних оценок (Excel/CSV)
- **Приоритеты оценок во вкладке «Тесты»:**
  - **Приоритет 1**: Оценки из таблицы `student_io` (актуальные данные студентов)
  - **Приоритет 2**: Оценки из таблицы `peresdachi` (ранее обработанные пересдачи)
  - **Приоритет 3**: Оценки из загруженного файла
- Во вкладке «Проекты» итог равен округлённому среднему максимальной оценки за задание и максимальной оценки за тест. Строки без одной из двух оценок пропускаются.
- Автоматическое определение новых записей (сравнение с БД)
- Удаление дубликатов перед сохранением
- В `peresdachi` сохраняются новые записи. Во вкладке «Проекты» рассчитанные оценки также обновляются в `final_grades`.
- Очистка данных от лишних символов и пробелов
- Преобразование данных melt (wide → long format)
- Автоматическое сопоставление со списком студентов из Supabase
- Раздельный вывод: все обработанные / только новые записи
- Экспорт обработанных данных в Excel (два варианта)
- Статистика по дисциплинам и студентам

#### 5. Аналитика курсов
- Обработка данных по трем курсам: ЦГ (Цифровая грамотность), Python, Анализ данных
- Расчет процента завершения курсов
- **Фильтрация студентов:**
  - Уровень образования: Бакалавриат, Специалитет
  - Курс: Курс 1, Курс 2, Курс 3, Курс 4
- UPSERT в отдельные таблицы: `course_cg`, `course_python`, `course_analysis`
- Сводная статистика по курсам
- Автоматическая фильтрация данных ЦГ

#### 6. Обновление списка студентов
- **Защищено паролем** (требуется авторизация)
- Загрузка данных студентов из Excel/CSV
- Автоматическое удаление дубликатов по email
- UPSERT в таблицу `students` (обновление + добавление)
- Поддержка множественных форматов (Excel, CSV с разными кодировками)
- Валидация корпоративной почты (@edu.hse.ru)
- Пакетная обработка (200 записей на батч)
- Retry-логика при сетевых ошибках

**Таблица `students`:**
- корпоративная_почта (primary key), фио, филиал_кампус
- факультет, образовательная_программа, версия_образовательной_программы
- группа, курс, уровень_образования

## Конфигурация

### 1. Настройка секретов

Создайте файл `.streamlit/secrets.toml` в корне проекта:

```toml
[supabase]
url = "https://your-project.supabase.co"
key = "your-supabase-anon-key"

NEBIUS_API_KEY = "your-nebius-api-key"
```

**Где взять ключи:**
- **Supabase**: [supabase.com](https://supabase.com) → Project Settings → API
- **Nebius AI**: Свяжитесь с администратором или получите на [nebius.ai](https://nebius.ai)

### 2. Настройка базы данных

Необходимо создать следующие таблицы в Supabase:

**1. Таблица `students`** (основной справочник студентов)
```sql
CREATE TABLE students (
    корпоративная_почта TEXT PRIMARY KEY,
    фио TEXT,
    филиал_кампус TEXT,
    факультет TEXT,
    образовательная_программа TEXT,
    версия_образовательной_программы TEXT,
    группа TEXT,
    курс TEXT,
    уровень_образования TEXT
);
```

**2. Таблица `peresdachi`** (результаты внешних оценок)
```sql
-- См. файл sql/create_peresdachi_table.sql для полной схемы
```

**3. Таблицы аналитики курсов**
```sql
CREATE TABLE course_cg (
    корпоративная_почта TEXT PRIMARY KEY,
```

**Примечание:** Все SQL-скрипты находятся в папке `sql/`

## Использование

Подробные инструкции по каждому модулю:

### Генератор HTML-карточек
1. Введите текст объявления в текстовое поле
2. Нажмите "Сформировать HTML"
3. Просмотрите результат (код слева, предпросмотр справа)
4. Скачайте или скопируйте готовый HTML

### Обработка пересдач
1. Загрузите файл с оценками (требуемые колонки: Email, Тест:Входное/Промежуточное/Итоговое тестирование)
2. Система автоматически загрузит студентов из Supabase
3. Обработает оценки и сохранит в таблицу `peresdachi`
4. Скачайте все записи или только новые

### Аналитика курсов
1. Загрузите файлы трёх курсов (ЦГ, Python, Анализ данных)
2. Нажмите "Обработать курсы"
3. Данные загрузятся в отдельные таблицы с UPSERT
4. Просмотрите статистику по завершению

### Обновление списка студентов
1. Введите пароль для авторизации
2. Подготовьте файл с данными студентов (Excel/CSV)
3. Загрузите файл (автоматическое распознавание колонок)
4. Нажмите "Обновить список студентов"

### Примеры файлов

В папке `examples/` находятся образцы файлов:
- `Сертификаты пример.xlsx` — шаблон данных студентов
- `агрегированные_навыки.xlsx` — справочник навыков

## API и интеграции

### Supabase

**Конфигурация клиента:**
```python
from utils import get_supabase_client

supabase = get_supabase_client()
response = supabase.table('students').select('*').execute()
```

**Таблицы:**
- `students` — справочник студентов (ФИО, email, группа, курс, факультет)
- `student_io` — актуальные оценки студентов (используется для приоритетных оценок)
- `peresdachi` — результаты внешних оценок и пересдач
- `course_cg`, `course_python`, `course_analysis` — аналитика курсов

**Ключевые поля таблицы `peresdachi`:**
- `Адрес электронной почты` + `Наименование дисциплины` — уникальный ключ
- `ФИО`, `Кампус`, `Факультет`, `Образовательная программа`
- `Группа`, `Курс`, `ID дисциплины`, `Период аттестации`
- `Оценка` — итоговая оценка с учетом приоритетов

### Nebius AI

**Генерация HTML-карточек и обложек:**
```python
from constants import NEBIUS_MODEL
from utils import get_nebius_client

client = get_nebius_client()
response = client.chat.completions.create(
    model=NEBIUS_MODEL,
    messages=[...]
)
```

- Все ключи API в `.streamlit/secrets.toml`

## Особенности обработки данных

### Автоматическая фильтрация
- **Курс ЦГ**: исключение вспомогательных материалов, консультаций, демо-версий
- **Студенты**: только корпоративная почта @edu.hse.ru

### Дедупликация
- Email нормализуется (lowercase, trim)
- Сохраняется первая запись при совпадении
- Статистика дубликатов

### Пакетная обработка
- Batch size: 200 записей
- Retry-механизм при сетевых ошибках (2 попытки)
- Progress indicators

## Известные ограничения

- Supabase API ограничение: 1000 записей за запрос (реализована пагинация)
- Только HSE корпоративные почты (@edu.hse.ru) для таблицы students
- Требуется наличие таблиц `students`, `student_io` для модуля 4 (внешние оценки)
- Генератор HTML-карточек требует активный API ключ Nebius AI
- Модуль 4: дубликаты определяются по комбинации email + дисциплина
- Модуль 4: приоритет оценок: student_io > peresdachi > файл
